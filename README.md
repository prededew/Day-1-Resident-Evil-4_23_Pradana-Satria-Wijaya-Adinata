Rangkuman Materi Misi yg ada di Day-1 yaitu mengenai Git & Github langkah-langkah membuat repository dan menghubungkannya dengan project

1. Pengertian Git dan GitHub
- Git: Sistem version control untuk mencatat dan melacak perubahan file dalam proyek secara lokal.
- GitHub: Platform online untuk menyimpan repository Git dan memudahkan kolaborasi.
2. Alur Kerja Git (Git Workflow)

Git memiliki tiga area utama:
- Working Directory: Tempat mengedit dan mengubah file proyek.
- Staging Area: Tempat menyiapkan file sebelum disimpan.
- Git Directory (Repository): Tempat menyimpan riwayat perubahan proyek.
3. Cara Membuat Repository di GitHub
1. Buka website GitHub.
2. Klik New Repository.
3. Masukkan nama repository.
4. Klik Create Repository.
5. Klik tombol Code, lalu salin link HTTPS.
4. Langkah Menghubungkan Project ke GitHub

Berikut urutan perintah Git melalui Terminal atau Command Prompt:
Perintah	Fungsi
git init	Menginisialisasi Git pada folder proyek.
git add .	Memasukkan seluruh file ke staging area.
git commit -m "pesan"	Menyimpan perubahan dengan pesan.
git remote add origin URL	Menghubungkan proyek lokal ke GitHub.
git push -u origin main	Mengirim file ke repository GitHub.

5. Kesimpulan

Git digunakan untuk mengelola dan melacak perubahan pada proyek, sedangkan GitHub digunakan untuk menyimpan proyek secara online. Dengan Git dan GitHub, pekerjaan menjadi lebih teratur, aman, dan mudah dikembangkan maupun dikerjakan bersama tim.
